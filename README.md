# RxModel-Studio
View, inspect and convert the 3D character models from Studio Saizensen games built on rrlib / OpenDraw (Umihara Kawase BaZooKa!). Single offline EXE for Windows x64: mouse orbit, mesh/material/skeleton browsers, smooth shading, wireframe, cel and clay styles, PNG/DDS textures, OBJ export and byte-exact rebuild.
